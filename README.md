# okonovurmat.github.io

Personal website of Urmat Okonov — Senior iOS Developer.

- `/` — iOS developer portfolio (skills, own apps, commercial projects, experience, CV download)
- `/ai-engineer/` — AI Engineer CV (template, to be filled)

## Deploy on GitHub Pages

1. Create a public repository named **`OkonovUrmat.github.io`**.
2. Upload all files from this folder to the root of the `main` branch.
3. Settings → Pages → Source: *Deploy from a branch*, Branch: `main` / `(root)`.
4. The site will be live at https://okonovurmat.github.io/ (AI page: https://okonovurmat.github.io/ai-engineer/).

Existing project sites keep working, e.g. https://okonovurmat.github.io/Tamfu/.
